# DSA Coding Problem Screenshot Watcher

🔥 **Advanced DSA Problem Solver** - Automatically processes screenshots of coding problems and generates comprehensive Python solutions with multiple approaches, optimizations, and test case fixes.

## 🚀 Features

- **4-Screenshot Batch Processing**: Analyzes multiple screenshots together for comprehensive problem understanding
- **DSA Problem Expert**: Specialized in Data Structures & Algorithms problems
- **Multiple Solution Approaches**: Provides brute force → optimal solutions with complexity analysis
- **Failed Test Case Fixes**: Identifies and corrects issues in failing test cases
- **Comprehensive Test Cases**: Generates thorough test coverage including edge cases
- **Smart Notifications**: Sends solutions via Telegram and/or ntfy.sh
- **Clean Code Generation**: Produces well-commented, executable Python code

## 📋 Key Differences from Original Watcher

| Feature | Original Watcher | DSA Watcher |
|---------|------------------|-------------|
| Batch Size | 2 screenshots | **4 screenshots** |

## 🎯 How It Works

1. **Screenshot Upload**: Upload 4 screenshots containing DSA problems to Oracle Cloud bucket
2. **Batch Processing**: Watcher detects 4 new screenshots and processes them together
3. **Problem Analysis**: GPT-4o analyzes all screenshots for complete problem context
4. **Solution Generation**: Creates multiple solution approaches with optimizations
5. **Code Output**: Saves comprehensive Python solutions with test cases
6. **Notifications**: Sends results via configured notification methods

## 📸 Supported Screenshot Content

- **LeetCode Problems**: Complete problem statements, examples, constraints
- **Coding Interview Questions**: Algorithm challenges, data structure problems
- **Failed Test Cases**: Screenshots showing failing tests that need fixes
- **Code Snippets**: Partial implementations that need completion/optimization
- **Problem Descriptions**: Text-based algorithm problems

## 🔥 Pro Tips

1. **Screenshot Quality**: Ensure text is clear and readable
2. **Complete Context**: Include all relevant problem information across the 4 screenshots
3. **Failed Tests**: If showing failed tests, include the expected vs actual output
4. **Constraints**: Make sure constraint information is visible
5. **Examples**: Include input/output examples for better solution accuracy

## 🛟 Troubleshooting

### Common Issues
- **Empty Solutions**: Check if screenshots contain clear problem statements
- **API Errors**: Verify OpenAI API key and rate limits
- **Upload Issues**: Ensure Oracle Cloud bucket permissions are correct
- **Notification Failures**: Check Telegram/ntfy credentials
